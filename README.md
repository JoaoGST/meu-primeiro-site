# 🌐 Meu Primeiro Site

Bem-vindo ao meu **primeiro projeto de site**! 😄  
Este projeto é uma página web simples feita com **HTML e CSS**, incluindo ícones personalizados (favicons). É um aprendizado de desenvolvimento web básico, mas organizado e funcional!  

---

## 🚀 Como Visualizar

1. Clone ou baixe o repositório:
   ```bash
   git clone https://github.com/seuusuario/meu-primeiro-site.git
2. Abra o arquivo index.html no seu navegador preferido.
   💡 Dica: Também é possível usar o GitHub Pages para visualizar online diretamente pelo GitHub.

---

✨ Funcionalidades

- Página inicial com HTML básico
- Estilização personalizada com CSS
- Favicons configurados para navegador
- Estrutura de pastas organizada
